## 数据质量检查
- 含多类缺陷的图：123 张（标注里出现非主类别框，属 NEU-DET 原始多标签标注，非错标）
- 无 XML 的图像：0（无）-> 按背景图处理，标签为空文件
- 无图像的 XML：0（无）
- 重复标注文件：0
- 内容重复（MD5）图像组：1（同组图像强制划分到同一 split，避免泄漏）
- 丢弃的退化/未知类别框：0

> 划分说明：本划分是对全部 1800 张图像重新做的分层随机划分，未沿用镜像自带的 split；未按钢板/批次分组，因此同一母卷图像可能同时出现在 train 与 val，存在同源泄漏风险（见 README 局限）。
